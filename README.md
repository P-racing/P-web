# 웹사이트 기본 구조

- `index.html`: 페이지 내용과 구조
- `css/style.css`: 색상, 글꼴, 배치 등 디자인
- `js/main.js`: 페이지 동작
- `assets/`: 로고와 사진 등 이미지 파일

## 시작하기

`index.html` 파일을 더블 클릭하면 브라우저에서 볼 수 있습니다. 텍스트 편집기로 각 파일을 열어 원하는 내용으로 수정하세요.

## 로고 넣기

로고 파일을 `assets/logo.png`로 저장한 다음, `index.html` 상단의 로고 안내 주석을 참고해 텍스트 로고를 이미지 코드로 바꾸세요. 파일 이름이나 확장자가 다르면 `src`도 같은 이름으로 수정하세요.
